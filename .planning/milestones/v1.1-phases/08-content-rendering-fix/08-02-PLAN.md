<objective>
Close, or explicitly and visibly carry forward, the single largest open risk in this phase's CONT-05 half: the emptiness heuristic has never been observed against a genuinely content-empty public Notion page.

Purpose: `08-RESEARCH.md` Finding 4 flags the threshold `[ASSUMED]` (Assumptions Log A1) — the traversal logic was read correctly out of `notion-client`, but nobody has checked whether Notion attaches a default child block (an empty paragraph, say) to a blank page. If it does, every empty post silently takes the *fetch-failed* branch and tells readers the site broke when it did not. `08-VALIDATION.md` is explicit that this check happens **before** shipping, not after. This plan is that check, and it must land before plan 08-04's single deploy so a corrected threshold rides the same deploy (D-14).

Output: an observed block count from a real empty Notion page, `RENDERABLE_BLOCK_MIN` set to a value that count justifies, and the `[ASSUMED]` marker in its comment either removed with the evidence cited or deliberately left in place with the residual risk recorded.
</objective>

  <what-built>
    Plan 08-01 shipped `isRecordMapEmpty(recordMap)` in `apps/web/src/lib/notion-x.ts`, which reports a page as having nothing to render when the number of keys in `recordMap.block` is below `RENDERABLE_BLOCK_MIN` (shipped value: `2`). That value rests on a code-reading argument — `notion-client`'s `getPage()` throws before returning when `block` is entirely absent, so any record map that reaches the predicate carries at least the page's own container block, and exactly one entry means no content children. Nobody has ever watched a real empty Notion page produce that number.
  </what-built>
  <how-to-verify>

Copy its page id.

    **Step 2 — read the authoritative count.** From the `apps/web` directory (so `notion-client` resolves), with `UAT_EMPTY_PAGE_ID` set to that id, run:

    `node -e 'const {NotionAPI}=require("notion-client");const fs=require("fs");const ua=fs.readFileSync("src/lib/notion-x.ts","utf8").match(/NOLOG_USER_AGENT\s*=\s*"([^"]+)"/)[1];new NotionAPI({ofetchOptions:{headers:{"User-Agent":ua}}}).getPage(process.env.UAT_EMPTY_PAGE_ID).then(rm=>console.log("blockKeys="+Object.keys(rm.block??{}).length)).catch(e=>console.log("THREW: "+e.message))'`
