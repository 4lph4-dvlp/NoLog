<objective>
Run Phase 7's two outstanding UAT tests and record their results, per 08-CONTEXT D-15.

Purpose: Phase 7 scored 3/4 and sits at `human_needed`. Its SC#3 (a chrome-leg failure must not blank the post body) and SC#4 (a transient `getPost` failure must render `PostUnavailable`, not a 404) are `PRESENT_BEHAVIOR_UNVERIFIED` — the code was read and judged correct, but neither state transition was ever observed. SC#3 in particular was **masked**: while the content leg was failing for an unrelated reason, "the body did not render" was ambiguous between the two causes. Plan 08-01's fix removes that ambiguity, which is why `07-UAT.md`'s own ordering note says to run this test after Phase 8's fix lands. Doing it here uses the same build and avoids dragging an unfinished phase into the milestone audit.

These two tests are legitimately **local**, unlike CONT-03. PITFALLS 12 rules out `next dev` for *environmental* bugs; SC#3 and SC#4 are pure control-flow properties of `post/[id]/page.tsx` that behave identically wherever the code runs — and inducing them locally is the only safe option, since the alternative is deliberately breaking the live blog's Notion access to watch what happens. Use a production build (`npm run build && npm start`), never `next dev`.

Output: both tests observed, both recorded in `07-UAT.md` with outcomes and timestamps, and a working tree with every fault injection reverted.
</objective>
