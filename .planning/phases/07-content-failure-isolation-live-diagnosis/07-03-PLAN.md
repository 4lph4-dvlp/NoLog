Phase 9 (IMG-01) requires an uninterrupted idle window longer than Notion's ~1h presigned-URL lifetime; this plan's redeploys reset that window. - **Hobby log retention is ~1 hour** (07-RESEARCH.md, Vercel runtime-logs docs). The debug-route trigger and the dashboard log copy must happen in one sitting. A log line copied from memory 90 minutes later is not evidence — it is the exact failure mode the prohibition in `must_haves` forbids.
- **PITFALLS 15.** A page that renders once proves nothing: the cache may be warm, or the cause intermittent. The capture repeats the page load several times across several minutes.
