## Tracer-first shape

Task 1 is the `tracer`: one complete configure-and-deploy path wired through **both** language surfaces at once. It is production-quality prose, not a draft — a forker can follow it end to end the moment it lands. Task 2 is the expansion task in the MVP "validation + error states" slot: it hardens that same slice with the failure-mode warnings and the quota disambiguation. Splitting by language (README.md fully, then README_KR.md fully) is explicitly rejected — that is a horizontal layer wearing a slice label, and it would ship a half-translated document at the wave boundary.

## Reversibility

Every decision this plan implements (D-01 through D-09) is `reversible`: the undo is a scoped edit to two Markdown files in one commit, with no migration, no published contract, and no dependent system reading the output. No `one-way` or `costly` door was found, so no `<reversibility>` element and no `checkpoint:decision` gate is emitted (per `references/planner-reversibility.md`: *when unsure, rate it reversible; a planner that rates everything one-way produces checkpoint fatigue*).
